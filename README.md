# Movie Card

A movie card project created using HTML and CSS.

## About

This project is a movie information card designed for The Social Network.

It includes:

- Movie poster
- IMDb rating
- Release year
- Genre
- Director
- Duration
- Movie summary
- IMDb review button

## Technologies

- HTML5
- CSS3
- Font Awesome

## Features

- Custom movie card design
- Neon technology-themed background
- Styled movie information section
- IMDb link button
- Hover effects

## Preview

The project features a dark technology-inspired design with neon green details.
